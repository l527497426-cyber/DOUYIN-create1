# 创作者中心

面向内容创作者的工作台，将创作入口、账号表现、互动消息与收益信息集中呈现，提供清晰、高效的创作管理体验。

## 功能概览

- 创作入口与内容推荐，帮助发现灵感、开启创作。
- 数据可视化与趋势分析，直观了解账号表现。
- 互动、活动与收益概览，便捷掌握运营动态。
- 自适应桌面布局与流畅交互，兼顾信息阅读和操作体验。

## 本地运行

安装 Node.js 后，在项目目录执行：

```bash
npm start
```

打开 [本地预览](http://localhost:5173)。

## 技术与部署

使用 HTML、CSS 和 JavaScript 构建，支持通过 Vercel 部署。

当前版本为前端交互演示，账号数据及业务服务尚未接入。
