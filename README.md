## 交互规范

- 入场：页面 700ms 淡入并上移14px；五张卡片800ms上移22px，逐张间隔90ms。
- 漂浮：5.6–7.2秒各自循环，上下8px、轻微0.6°旋转，错开相位。
- 悬停/键盘焦点：立即置顶；450ms抬升10px、放大1.06；冻结当前漂浮相位，退出从同一相位继续。
- 鼠标移动：最大水平4.5°、垂直3.5°透视倾斜，局部光泽跟随；350ms后显示完整说明。
- 按压：缩至1.025；点击固定当前卡片，再次点击解除；其他卡片仍可悬停置顶。
- 左右方向键切换卡片，Escape取消固定；焦点轮廓可见；系统减少动态偏好下关闭动画。
- 页面后台暂停循环，减少耗电。按钮、导航、素材、数据卡均有hover反馈。业务链接仅提示预览状态，没有伪造业务结果。
